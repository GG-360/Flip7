# Flip 7 Punkte

Punkte-Rechner für das Kartenspiel Flip 7. Installierbare Web-App (PWA), läuft offline, Daten bleiben auf dem Handy.

## Veröffentlichen
Repository **Settings > Pages**: Source `Deploy from a branch`, Branch `main`, Ordner `/ (root)`.
Nach etwa einer Minute erreichbar unter `https://gg-360.github.io/flip7/`.

## Aufs Handy (Android)
Link in Chrome öffnen, Menü ⋮, **App installieren**.

## Wertung
Zahlenkarten addieren, ×2 verdoppelt nur die Zahlen, dann +Modifikatoren, 7 verschiedene Zahlen = +15 (Flip 7). Bust = 0. Spielende ab 200 Punkten.
